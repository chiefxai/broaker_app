Accessibility and responsive rules

These rules apply to every screen and reusable component.

Accessible controls

Give controls a role, useful label, selected/disabled/busy state, and visible keyboard focus. Aim for 44 px touch targets.

Color and text

Maintain contrast in both themes. Never communicate status by color alone. Support larger text without clipping.

Small screens

Use flexible widths and vertical scrolling. Allow chip rows to scroll horizontally; prevent page-level horizontal overflow.

Platform behavior

Use native React Native controls and safe areas. Handle web focus and keyboard behavior where it differs from mobile.

Component ownership

Components receive typed data and callbacks. Screens own fetching, persistence, navigation, and feature rules.

Source of truth

App tokens live in src/theme/tokens.ts; component exports are listed in the core component registries.
